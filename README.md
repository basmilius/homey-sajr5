# SAJ R5 for Homey

Monitor a SAJ R5 solar inverter from Homey over Modbus TCP. The app reads the inverter on your local network and exposes solar production and operating measurements as Homey device capabilities.

## Measurements

- Solar output power and total PV input power.
- Individual PV input power for up to three inputs.
- AC current per phase and inverter temperature.
- Daily and total energy yield.

These capabilities make inverter readings available in Homey for monitoring and automations.

## Setup

The app targets local Homey version 5.0 or newer. Your inverter must be reachable from Homey over Modbus TCP.

Add a SAJ R5 inverter and configure its IP address and port. The default port is `502`. Device settings also include maximum peak power and a polling interval, which defaults to 10 seconds with a minimum of 5 seconds.

## Source layout

`drivers/inverter/` contains pairing, device settings and the Modbus polling implementation. The app uses `jsmodbus` for communication. Capability definitions and Flow metadata live under `.homeycompose/`.

## Development

Use Bun for dependencies and scripts. Run these commands from the repository root:

```sh
bun install
bun run build
```

Edit Homey metadata in `.homeycompose/` and driver compose files where present. The root `app.json` is generated by Homey. `README.txt` and its translations contain the Homey App Store description; this Markdown file documents the GitHub project.
